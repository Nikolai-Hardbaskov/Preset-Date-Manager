# Preset Date Manager для SillyTavern

Расширение для мобильной и настольной SillyTavern: поиск пресетов, сортировка по дате и отображение дат рядом с названиями.

> **Статус:** тестовая версия 1.0.0. Синтаксис и серверный модуль проверялись отдельно, полноценная проверка внутри SillyTavern на Android пока не выполнена.

## Возможности

- Сортировка: сначала новые, сначала старые, по названию А–Я или Я–А.
- Отображение даты в формате ДД.ММ.ГГГГ.
- Быстрый поиск пресета по названию.
- Мобильное окно выбора вместо системного выпадающего списка.
- Поддержка Chat Completion, Text Completion, NovelAI, Kobold, а также шаблонов instruct/context/system prompt/reasoning.
- Оригинальные `<select>` и названия пресетов не изменяются; расширение не переписывает файлы пресетов.
- Выбранный порядок сохраняется для каждого типа пресетов в браузере.

## Установка из GitHub

1. Открой SillyTavern.
2. Перейди в меню **Extensions / Расширения** → **Install Extension / Установить расширение**.
3. Вставь адрес репозитория: `https://github.com/Nikolai-Hardbaskov/Preset-Date-Manager`.
4. Установи расширение и перезагрузи страницу SillyTavern.

Файлы `manifest.json`, `index.js` и `style.css` находятся в корне репозитория, как требуется установщику SillyTavern.

**Важно:** интерфейс устанавливается через меню расширений, но **для получения дат уже существующих файлов нужен отдельный серверный модуль**. Без него пресеты будут доступны для поиска и сортировки по названию, а вместо даты появится «Дата неизвестна».

## Установка серверного модуля дат

1. Скачай файл [server-plugin/preset-date-manager.js](server-plugin/preset-date-manager.js).
2. Скопируй его в директорию `SillyTavern/plugins/preset-date-manager.js` на устройстве, где работает сервер SillyTavern.
3. В файле `SillyTavern/config.yaml` включи `enableServerPlugins: true`.
4. Перезапусти **сервер SillyTavern**, а затем обнови страницу в браузере.

После установки модуль добавит маршрут `/api/plugins/preset-date-manager/dates` и будет возвращать метаданные файлов пресетов текущего пользователя. Содержимое пресетов не читается и не изменяется.

Серверные плагины имеют полный доступ к возможностям Node.js — устанавливай их только на сервер, который контролируешь, и после проверки кода.

## Какие даты показываются

Плагин читает **дату создания файла в файловой системе** (или дату изменения, если создание недоступно). Это **не гарантированная дата первоначальной загрузки пресета**: после копирования, переноса, резервного восстановления или переустановки SillyTavern дата может отличаться.

Если для пресета нет доступной даты, в списке будет «Дата неизвестна».

## Установка вручную

Скопируй файлы `manifest.json`, `index.js` и `style.css` в папку:

`SillyTavern/data/default-user/extensions/PresetDateManager/`

Если используешь другого пользователя SillyTavern, замени `default-user` его каталогом. Для установки для всех пользователей можно воспользоваться `SillyTavern/public/scripts/extensions/third-party/PresetDateManager/`.

## Удаление

Удалите UI-расширение через менеджер расширений. Если установлен серверный модуль, удалите `SillyTavern/plugins/preset-date-manager.js` и перезапустите сервер. Файлы пресетов останутся нетронутыми.

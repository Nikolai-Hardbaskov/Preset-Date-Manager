# Preset Date Manager для SillyTavern

**Версия 1.1.0 — расширение полностью работает без серверного модуля.**

Мобильный и настольный менеджер пресетов: поиск по названию, сортировка по дате или алфавиту, даты рядом с названиями, ручная корректировка дат.

## Возможности

- Сначала новые / сначала старые / по алфавиту А–Я / Я–А.
- Поиск пресетов по названию.
- Дата рядом с каждым пресетом в формате **ДД.ММ.ГГГГ**.
- Кнопка **✎** для исправления даты любого пресета.
- Автоматическая запись даты первого обнаружения пресета расширением.
- Хранение данных в обычных пользовательских настройках SillyTavern (`extensionSettings`), с резервным сохранением в браузере, если контекст недоступен.
- Работает на телефоне и на компьютере; оригинальный список `<select>` остаётся нетронутым.
- Поддерживаются Chat Completion, Text Completion, NovelAI, Kobold, instruct, context, system prompt, reasoning.

## Установка через GitHub

1. В SillyTavern открой **Extensions → Install Extension**.
2. Вставь `https://github.com/Nikolai-Hardbaskov/Preset-Date-Manager`.
3. Установи расширение и перезагрузи страницу.

Если расширение было установлено раньше, выполни обновление через **Manage Extensions** и перезагрузи страницу.

**Ничего копировать в `SillyTavern/plugins` не нужно.** Включать `enableServerPlugins` тоже не нужно.

## Откуда берутся даты?

**Важное ограничение:** стандартный API SillyTavern не сообщает, когда старый пресет был первоначально импортирован. Ни один обычный браузерный скрипт не может надёжно восстановить такую дату по одному названию.

Поэтому при первом запуске расширение запомнит **дату первого обнаружения** уже существующих пресетов. Это не обязательно дата, когда ты их загрузил! Такие даты подписаны «первое обнаружение».

Если ты знаешь настоящую дату импорта старого пресета:

1. Открой окно выбора пресетов.
2. Нажми **✎** справа от нужного названия.
3. Введи дату в формате **ДД.ММ.ГГГГ**.
4. Список сразу пересортируется, а дата сохранится в настройках.

Новые пресеты будут автоматически получать дату, когда расширение впервые заметило их в списке. Если расширение открыто в момент импорта, дата обычно совпадёт с днём импорта.

Времена изменения файлов, их создание в ОС и история первоначального импорта — разные сведения. Не следует считать дату первого обнаружения датой импорта без дополнительного подтверждения.

## Установка вручную

Помести `manifest.json`, `index.js`, `style.css` в `SillyTavern/data/default-user/extensions/PresetDateManager/`.

## Замечания

- Даты отслеживаются по типу пресета и **названию**. При переименовании запись о старом названии остаётся в настройках, а новое название получает новую дату обнаружения.
- Изменения хранятся в настройках SillyTavern и сохраняются через стандартный механизм настроек. В резервном режиме localStorage даты хранятся только на текущем устройстве.
- **Статус:** тестовая версия. Проверен синтаксис клиентского скрипта, но работа в реальном интерфейсе SillyTavern на Android требует проверки.
